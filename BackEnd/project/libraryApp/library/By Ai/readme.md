## النظام

### المستخدمون (Users)

- تسجيل الدخول.
- تغيير كلمة المرور.
- إدارة الصلاحيات (Role & Permissions).

### الكتب (Books)


- إضافة كتاب.
- تعديل بيانات كتاب.
- حذف كتاب.
- البحث بالاسم.
- البحث بالمؤلف.
- البحث بالتصنيف.
- البحث بـ ISBN.
- معرفة عدد النسخ.

### المؤلفون (Authors)

- إضافة مؤلف.
- تعديل.
- حذف.
- عرض جميع كتب المؤلف.

### التصنيفات (Categories)

- إضافة تصنيف.
- تعديل.
- حذف.
- عرض الكتب داخل التصنيف.

### الناشرون (Publishers)

- إدارة دور النشر.

### العملاء (Customers)

- إضافة عميل.
- تعديل البيانات.
- سجل الاستعارات أو المشتريات.

### المبيعات

- إنشاء فاتورة.
- إضافة عدة كتب.
- حساب الإجمالي.
- تحديث المخزون تلقائيًا.

### الاستعارات (اختياري إذا كانت المكتبة تؤجر الكتب)

- استعارة كتاب.
- تاريخ الإرجاع.
- الغرامات.
- الكتب المتأخرة.

### المخزون

- عدد النسخ.
- تنبيه عند قرب نفاد المخزون.
- سجل حركة المخزون.

### التقارير

- أكثر الكتب مبيعًا.
- المبيعات اليومية.
- المبيعات الشهرية.
- الأرباح.
- الكتب المنتهية.

### الإعدادات

- بيانات المكتبة.
- الضرائب.
- العملة.
